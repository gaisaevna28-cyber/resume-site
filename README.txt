ОТБОР АНАЛИТИКОВ — локальный сайт
=================================
Как открыть: распакуйте архив и дважды щёлкните index.html (подойдёт любой современный браузер: Chrome, Edge, Firefox). Интернет не нужен.

Структура
  index.html        главная (статистика, воронка, лидеры)
  candidates.html   все кандидаты: поиск, фильтры, карточки и таблица
  candidate.html    профиль кандидата (открывается по клику из списка)
  tests.html        тестирование: сдали, ждём ответ, не выдавалось
  summary.html      сводные таблицы по уровням, общая таблица, документы
  library.html      все файлы с поиском и фильтром по типу
  method.html       методика отбора, шкала баллов, структура хранилища
  css/style.css     оформление
  js/               скрипты; js/data.js содержит данные всех кандидатов
  files/            все документы для скачивания:
    resumes/        резюме (оригиналы)
    assessments/    первичные оценки
    tasks/          тестовые задания для кандидатов
    checks/         «Что проверяем» (внутренние, кандидату не отправлять)
    answers/        ответы кандидатов
    reviews/        проверки ответов (баллы, оценка риска ИИ)
    reports/        сводные таблицы и критерии проверки

Имена файлов латиницей: {кандидат}-resume.doc, {кандидат}-task.docx и т.д. Общий префикс связывает файлы одного кандидата.
Оригиналы лежат в папках «кандидаты» и «новые кандидаты»; сайт хранит их копии.
